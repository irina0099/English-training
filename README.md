# English Notebook

Персональный тренажёр английского для уровней B1 и B2. Короткие задания на слова и разговорные фразы, повторение по расписанию, журнал частых ошибок с правилами и словесные игры. Тренажёр запоминает, где вы ошибаетесь, и чаще возвращает вас к этим местам.

## Что внутри

**Материалы**
- ≈210 частотных слов B1 и ≈180 слов B2: самые употребительные глаголы, существительные, прилагательные и слова‑связки (по спискам Oxford 3000/5000). У каждого слова есть перевод, пример с переводом, а у многих — заметка об употреблении (например, *afford + to do*).
- 134 фразовых глагола в 49 «семьях» по базовому глаголу: *get up, get on with, get over, get away with…*, *take off, take after, take up…*, *look after, look forward to…* и т. д. У каждого есть значение, пример с переводом и, где нужно, заметка (например, можно ли поставить объект между глаголом и частицей). Отбор — по частотному списку PHaVE.
- 86 разговорных фраз (*It depends*, *I’d rather not*, *Keep me posted*, *It sounds like…*…). Для каждой описана ситуация, в которой её говорят.
- 31 грамматическое правило про типичные ошибки русскоговорящих: предлоги, артикли, make/do, -ing или to, *I agree* вместо *I am agree*, ложные друзья переводчика, условные предложения, будущее время, *too/enough*, *so/such*, *must have done*, Past Perfect и т. д. У каждого правила есть короткая сводка, подробности и примеры «правильно / неправильно».
- ≈165 грамматических заданий, привязанных к правилам.

**Свои слова.** Слова можно добавлять по одному или списком (`слово — перевод — пример`, можно вставить прямо из таблицы). В примере тренажёр сам находит слово, в том числе в формах *decided*, *studying*, *stopped*, чтобы сделать из примера задание с пропуском. Свои слова участвуют в тренировках и играх, а в разделе «Мои слова» их можно тренировать отдельно.

**Типы заданий** (тип зависит от того, насколько хорошо вы знаете слово):
- новое слово: карточка с примером, затем выбор перевода;
- «Как сказать по-английски?»: выбор из четырёх вариантов, для фраз — по описанию ситуации;
- «Напишите по-английски» и «Вставьте слово в пример». Подсказка открывает первую букву. Если вы написали верный синоним, нажмите «Мой ответ тоже верный»;
- «Соберите фразу» из слов;
- «Choose the particle» для фразовых глаголов: в примере пропущена частица (*Do you get ___ your colleagues?*), варианты — частицы того же глагола;
- грамматика: выбор варианта, ввод ответа, «Какое предложение правильное?».

После каждого ответа показываются пример употребления и короткое правило «Почему так» со ссылкой на полное объяснение. Ошибка выводится как исправление красной ручкой.

**Повторение по расписанию.** Используется модель FSRS‑4.5. Кнопки «легко / трудно» нажимать не нужно, оценка ставится сама:
- ошибка — *Again*;
- опечатка или ответ с подсказкой — *Hard*;
- верный ответ — *Good*;
- быстрый верный ответ с вводом текста — *Easy*.

Задание, в котором вы ошиблись, повторяется в той же тренировке через 3–5 заданий и в другом формате.

**Персонализация**
- Тренировка складывается так: около 60% — повторения, которые пора сделать, около 25% — слабые места, остальное — новые слова (в пределах дневного лимита).
- Вес ошибки уменьшается вдвое за неделю, поэтому тренажёр гоняет по тому, что трудно *сейчас*.
- Слабое правило подтягивает в тренировку и другие задания на это правило.
- Раздел «Ошибки» показывает, какие темы даются труднее всего, и повторяющиеся ошибки в виде «ваш ответ → правильно». Задание считается исправленным после трёх верных ответов подряд.
- Режимы «Работа над ошибками» и «Потренировать правило».

**Погружение в английский.** Весь интерфейс, задания, заметки к словам, ситуации для фраз и объяснения правил написаны на простом английском уровня B1. Русский остаётся там, где он действительно нужен:
- переводы слов;
- переводы примеров и предложений — скрыты за кнопкой «Show translation», их можно показывать сразу через «Settings → Always show translations»;
- русская версия каждого правила — по кнопке «RU» или «Русский».

**Фразовые глаголы.** «Words → Phrasal verbs» показывает глаголы семьями: *get* и все его сочетания со значениями и примерами. Кнопка «Practise» у каждой семьи запускает тренировку только по ней. Фразовые глаголы также входят в обычные тренировки, игры и карточки.

**Карточки (Flashcards).** Карточка переворачивается нажатием, после ответа — «Again» или «Got it». Порядок сторон можно переключить: EN → RU или RU → EN. Где их найти:
- «Mistakes → Flashcards» — колода из текущих ошибок;
- кнопка «Flashcards» во вкладке «Words» — колода из выбранного фильтра (мои слова, сложные, B1…).

«Got it» продвигает слово по расписанию и засчитывается в исправление ошибки. «Again» возвращает слово раньше.

**Игры** (на наборе слов B1, B2, «Mine» или «Tricky»):
- **Филворд**: сетка 5×5, 6×6 или 7×7 полностью заполнена словами, которые идут змейкой. Подсказки — русские переводы. Ваши и сложные слова ставятся в сетку первыми.
- **Анаграммы**: собрать слово из перемешанных букв по переводу.
- **Пары**: соединить слово и перевод на время.

В конце каждой игры появляется список «New to you?». Слова, которые вы не нашли, пропустили, открыли с подсказкой или перепутали, уже отмечены. Кнопка «Add to practice» отправляет отмеченные слова в «Mistakes → Words from games». Там они стоят первыми в очереди новых слов и остаются, пока вы трижды подряд не ответите на них верно.

**Дизайн в стиле iOS:**
- системный шрифт SF Pro и системные цвета iOS;
- списки как в «Настройках», сегментированные переключатели и переключатели‑тумблеры;
- шторки с «ручкой» и полупрозрачная панель вкладок; панель всегда прижата к низу экрана, прокручивается только содержимое над ней (так она не «уезжает» на iPhone после клавиатуры или резкой прокрутки);
- на главной — итоги дня в виде колец, как в «Активности»: ответы, новые слова, точность;
- буквы в играх оформлены как клавиши клавиатуры iPhone;
- светлая и тёмная тема переключаются вслед за системой.

**Прочее:** озвучка слов и примеров (через синтез речи браузера), установка на телефон как приложение (PWA, работает офлайн, на iPhone — «Поделиться → На экран „Домой“»), резервная копия прогресса.

## Где хранится прогресс

- Версия на GitHub Pages или локальная: в `localStorage` браузера. Перенос на другое устройство — через «Настройки → Резервная копия».
- Копия, опубликованная на claude.ai: в личном хранилище вашего аккаунта, поэтому прогресс общий для всех устройств (`src/engine/cloud.ts`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты (FSRS, проверка ответов, план тренировки, филворд, контент)
npm run build      # сборка в dist/
npm run build:artifact  # одна страница для публикации на claude.ai → dist-artifact/english-notebook.html
```

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` на каждый push в `main` прогоняет тесты, собирает приложение и выкладывает его на GitHub Pages. Один раз нужно включить Pages: **Settings → Pages → Source: GitHub Actions**.

## Как устроен код

```
src/content/     слова B1/B2, фразовые глаголы (phrasal.ts), фразы, правила, грамматические задания
src/engine/      логика без интерфейса:
  fsrs.ts          интервальное повторение
  check.ts         проверка ответа (сокращения, BrE/AmE, опечатки)
  session.ts       выбор заданий и упражнений, оценка ответа
  mistakes.ts      журнал ошибок и их вес
  filword.ts       генератор филворда
  words.ts         свои слова: разметка примера, импорт списком
  store.ts         сохранение прогресса
src/ui/          экраны на Preact
tests/           тесты Vitest
```

### Добавить слово в встроенный словарь

В `src/content/words-b1.ts` (или `words-b2.ts`) добавьте строку:

```ts
['afford', 'позволить себе', 'v', 'I can’t *afford* a new phone.', 'Я не могу позволить себе новый телефон.', { note: 'afford + to do', rule: 'verb-patterns' }],
```

Слово в примере выделяется `*звёздочками*`: так оно подсвечивается и превращается в задание с пропуском. Тесты в `tests/content.test.ts` проверят, что пример размечен, а ссылка на правило существует.

Фразовый глагол добавляется в `src/content/phrasal.ts`, строкой в `rows` семьи своего глагола (`verb: 'get'`):

```ts
['B1', 'get back', 'возвращаться', 'What time did you *get back* last night?', 'Во сколько ты вчера вернулся?'],
```

Если объект стоит между глаголом и частицей, отметьте обе части: `I’ll *pick* you *up* at the airport.` Так тренажёр сможет сделать задание «Choose the particle».
